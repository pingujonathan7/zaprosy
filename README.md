# Запросы

Маленькое окно-шпаргалка поверх браузера: список поисковых запросов, каждый копируется одной кнопкой.

Каждая строка — отдельный запрос.

| Элемент | Что делает |
|---|---|
| 📌 | Держать окно поверх всех окон (синий — включено) |
| Вырезать | ON — запрос исчезает после копирования, OFF — остаётся и подсвечивается |
| ☾ / ☀ | Тёмная и светлая тема |
| ↺ | Вернуть последний удалённый запрос (то же, что Cmd+Z) |
| ✎ | Редактор всего списка: вставить 100–300 строк разом |
| 📋 в строке | Скопировать запрос в буфер обмена |
| × в строке | Удалить эту строку |
| + внизу | Быстро добавить одну строку (Cmd+N) |

Размер и позиция окна, список, тема и состояние тумблеров сохраняются в
`~/Library/Application Support/ZaprosyPad/state.json` и восстанавливаются при следующем запуске.

## Сборка

Собирает GitHub Actions на macOS-раннере, файл `.github/workflows/build.yml`.

- Любой push в `main` — сборка появляется во вкладке **Actions** → нужный запуск → **Artifacts**.
- Push тега `v1.0.0` — готовый zip выкладывается в **Releases**.

Выпуск новой версии:

```bash
git add -A && git commit -m "новая версия" && git push
git tag v1.0.1 && git push origin v1.0.1
```

## Установка

1. Скачать `Zaprosy-macOS.zip` из релиза, распаковать.
2. Перетащить `Запросы.app` в папку «Программы».
3. Первый запуск — правый клик по иконке → **Открыть** → **Открыть** в диалоге.

Приложение не подписано сертификатом разработчика, поэтому macOS спрашивает подтверждение один раз.
Если вместо вопроса пишет, что приложение повреждено:

```bash
xattr -dr com.apple.quarantine "/Applications/Запросы.app"
```

## Запуск без сборки

```bash
python3 zaprosy.py
```

Нужен Python 3 с tkinter (подойдёт установщик с python.org).

## Ограничение

Когда Chrome развёрнут в настоящий полноэкранный режим, macOS не пускает поверх него никакие окна —
это правило системы. Держи Chrome обычным окном, растянутым на весь экран (Cmd+Option+D убирает Dock
и освобождает ещё немного места).
